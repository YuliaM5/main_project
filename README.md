# 🎬 КиноПоиск Telegram Bot

Telegram бот для поиска информации о фильмах через API КиноПоиска.

## ✨ Возможности

- 🎲 **Случайный фильм** - получайте случайный фильм из базы КиноПоиска
- 🔍 **Поиск по названию** - находите фильмы по названию
- 📊 **Подробная информация** - полная информация о фильме:
  - Название и год выпуска
  - Жанры и страна производства
  - Статус (вышел, снимается и т.д.)
  - Рейтинги КиноПоиска и IMDb
  - Краткое описание
  - Постер фильма

## Установка и настройка

Создайте виртуальное окружение (рекомендуется):

```python -m venv venv```

Активируйте виртуальное окружение:

**Windows:**

```venv\Scripts\activate```

**Linux:**

```source venv/bin/activate```

Установите зависимости из файла requirements.txt:

```pip install -r requirements.txt```

## Использование

### Запуск программы

```python main.py```

### Бот

Пишите команду /start в бот @examkino_bot

### Команды бота

- `/start` - начать работу с ботом, показать доступные команды
- `/random` - получить случайный фильм
- `/film` - начать поиск фильма по названию
- `/cancel` - отменить текущий поиск

### Формат вывода

Пример вывода фильма:

```
Название: Интерстеллар
Статус: завершён
Год выпуска: 2014
Жанр: фантастика, драма, приключения
Страна: США
Рейтинг на кп: 8.6
Рейтинг imdb: 8.6
Описание: Когда засуха, пыльные бури и вымирание растений...
```

### Ограничения API

+ Ограничения по количеству запросов на бесплатном тарифе
+ Не все фильмы имеют полную информацию
+ Региональные ограничения доступа
