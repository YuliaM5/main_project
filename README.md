# Kinopoisk API Клиент

Простой консольный клиент для работы с API Кинопоиска.

## Возможности

Программа предоставляет три функции:

+ Получение случайного фильма

+ Поиск фильма по названию

+ Расширенный поиск по параметрам

## Установка и настройка

Создайте виртуальное окружение (рекомендуется):

```python -m venv venv```

Активируйте виртуальное окружение:

Установите зависимости из файла requirements.txt:

```pip install -r requirements.txt```

## Использование

### Запуск программы

```python main.py```

### Главное меню

```
Добро пожаловать в Kinopoisk API клиент!
==================================================

Доступные команды:
1. Получить случайный фильм
2. Поиск фильма по названию
3. Расширенный поиск по параметрам
4. Выход
==================================================
```

### Опции поиска

+ Случайный фильм
+ Поиск по названию
+ Расширенный поиск

### Формат вывода

Пример вывода фильма:

```
Название: Интерстеллар
Статус: завершён
Год выпуска: 2014
Жанр: фантастика, драма, приключения
Страна: США
Рейтинг на кп: 8.6
Рейтинг imdb: 8.6
Описание: Когда засуха, пыльные бури и вымирание растений...
```

### Ограничения API

+ Ограничения по количеству запросов на бесплатном тарифе
+ Не все фильмы имеют полную информацию
+ Региональные ограничения доступа
